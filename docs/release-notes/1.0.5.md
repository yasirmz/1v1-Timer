Checked against anti-cheat.

- 1v1 Timer never touches a game: it never opens, reads or changes a game's memory, never puts code into it, never presses a key or button for you, and installs no driver. That is what Vanguard (Valorant), Easy Anti-Cheat (Fortnite) and VAC (Steam) ban for, and the timer does none of it.
- New tests keep it that way: they list every Windows function the timer uses, and fail if one for reading another program's memory, injecting code or faking input is ever added.
- The README has an anti-cheat section in all seven languages.

The timer itself works as in 1.0.4. Update from inside the app (the tray menu or Settings → Check now), or run this setup over your install: it keeps your settings.
