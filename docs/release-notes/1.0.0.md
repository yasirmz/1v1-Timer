The first 1v1 Timer: two stopwatches for 1v1 matches, on top of your game.

- Two timers side by side, always on top, that never take the focus from the game. Drag to move, drag an edge or corner to resize; the place and size are kept.
- Hotkeys on the keyboard, the mouse (middle, back, forward) and Xbox controllers. They only listen: the game still gets every key.
- Start / Stop / Reset, Start / Stop, Select Timer 1 and Select Timer 2, each with a key or mouse button and a controller button.
- Start Timer On Change, Transparent Background, Clickthrough, and four colors of your own (Timer, Selected Timer, Last 20 Seconds, Background).
- Timer 2 turns orange in the last 20 seconds before it reaches Timer 1's time.
- Seven languages: English, Arabic, Chinese, Russian, Spanish, Portuguese and German.
- Updates from inside the app.

Use Borderless or Windowed mode in your game: Windows shows no window over a game in exclusive fullscreen.
