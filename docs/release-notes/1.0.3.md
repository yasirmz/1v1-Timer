Lighter on your game, and any hotkey can be cleared.

- The timer never uses the graphics card any more: it is drawn on the CPU, so it takes nothing from your game's frames.
- With the timers stopped it uses next to no CPU (was 7% of a core with a PlayStation controller connected), and under 1% of the CPU while one runs (was about 2%, plus the graphics card). Measured on an 8-thread PC with a DualSense on USB.
- A controller is read in small batches instead of one report at a time (a DualSense sends thousands a second), and the controller threads sleep when none is connected.
- Every hotkey box has an × that clears it, keyboard and controller alike, so a key or button can stay free for the game.

Update from inside the app (the tray menu or Settings → Check now), or run this setup over your install: it keeps your settings.
